## v1.2 — 计划（以「新增功能」为主）

v1.1 之后的下一个功能版本，不再修 bug，专心加能力。

### 交互

- [ ] 多宠物同时运行（可开 2–3 只，各自独立位置与动画）
- [ ] 点击切换下一段动画（现在点击只播回应动画，改成可循环切换）
- [ ] 双击进入「锁定」：锁定后拖动不会移动，防误触
- [ ] 长按呼出快捷菜单（切换动画 / 大小 / 隐藏）

### 外观

- [ ] 主题配色（边框、阴影、点击光晕）
- [ ] 动画播放速度调节（0.5x – 2x）
- [ ] 透明度调节（30% – 100%）
- [ ] 记忆上次的大小与位置，重启后恢复

### 素材

- [ ] 远程素材加载：APK 不含素材，按需下载并缓存
- [ ] 支持导入本地自定义动画（用户自己的 webm）
- [ ] 素材包管理：查看已缓存、单段删除、一键清空

### 系统集成

- [ ] 更换应用图标
- [ ] 开机自启（可选开关，默认关）
- [ ] 通知栏快捷开关（显示 / 隐藏 / 暂停）
- [ ] 快捷方式：桌面图标一键显示 / 隐藏

### 说明

- 顺序不代表优先级，先做哪个看反馈
- 涉及素材分发的功能（远程加载、导入自定义）不受上游授权限制
